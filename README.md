# APXe Care

보행 기록을 확인하고 공유할 리포트를 구성하는 고객용 앱과 기관용 보행 리포트 체험 화면입니다.

- [고객용 앱](https://gojj1229.github.io/apxe-care/)
- [기관용 리포트](https://gojj1229.github.io/apxe-care/provider.html)

## 주요 기능

고객용 앱은 날짜별 걸음 기록, 기간별 보행 분석, 걸음 목표, 리포트 항목 선택, HTML·CSV 저장과 인쇄를 지원합니다. 기관용 리포트에서는 조회 기간·측정 조건·지표를 바꾸고, 원기록과 공유 범위를 확인할 수 있습니다.

휴대폰에서는 하단 탐색 메뉴, 터치에 맞춘 버튼, 화면 폭에 맞는 차트, 스크롤 가능한 원기록 표를 제공합니다.

## 체험 데이터

모든 사용자와 보행 기록은 가상 예시입니다. 실제 Haier 기기, 의료기관 또는 계정 서버와 연결되지 않으며 개인정보를 수집하지 않습니다. 걸음 목표만 이용자의 브라우저에 저장합니다. 리포트는 이용자가 직접 저장하며 의료기관에 자동 전송되지 않습니다.

## 실행

별도 빌드 없이 정적 웹 서버에서 `index.html` 또는 `provider.html`을 열면 됩니다. GitHub Pages는 `main` 브랜치 루트에서 배포합니다. 외부 스크립트·폰트·분석 도구 의존성이 없습니다.
